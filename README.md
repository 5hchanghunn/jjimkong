# 찜콩 (JJIMKONG)

카페나 도서관에서 자리를 비울 때 내 물건을 지켜 주는 아두이노 도난 방지 장치입니다.
주인의 휴대폰 블루투스 신호가 끊기면 스스로 경계를 시작하고, 돌아오면 스스로 해제합니다.

2026 아두이노 기반 스마트제어 실무과정 팀 프로젝트 (오창훈, 정주혁)

## 동작

| 상태 | 들어가는 조건 | 반응 |
|---|---|---|
| 대기 | 주인이 근처에 있음 | 초록 LED |
| 경계 | 휴대폰 신호가 5초 끊김 | 깃발 올림, 걸쇠 잠금, LCD 메시지 |
| 경고 | 초음파 센서에 2회 연속 접근 감지 | 노랑 LED, 짧은 경고음 |
| 경보 | 경고가 3초 지속되거나 장치를 들어 올림 | 빨강 LED, 사이렌, 경고등 |

해제는 휴대폰 신호가 다시 잡히거나, 보드 B의 버튼 4개를 정해진 순서로 누르면 됩니다.

## 구성

아두이노 우노 2대를 I2C(SDA, SCL, GND)로 연결합니다.

- **보드 A (감지)** `jjimkong_board_a/` : 센서를 읽고 상태를 판단하는 I2C 마스터
- **보드 B (잠금)** `jjimkong_board_b/` : 걸쇠와 비밀번호를 맡는 I2C 슬레이브 (주소 8)

### 보드 A 핀

| 부품 | 핀 |
|---|---|
| 초음파 센서 HC-SR04 | D12 (Trig), D10 (Echo) |
| 블루투스 HC-06 | D3 (수신), D11 (송신, 1 kΩ·2 kΩ 분압) |
| 서보 SG90 (깃발) | D9 |
| 부저 | D8 |
| LED 초록 / 노랑 / 빨강 | D2 / D4 / D5 |
| 가변저항 (경고 거리) | A0 |
| I2C LCD, 자이로 MPU6050, 보드 B | A4 (SDA), A5 (SCL) |

### 보드 B 핀

| 부품 | 핀 |
|---|---|
| 버튼 1, 2, 3, 4 | D5, D4, D3, D2 (INPUT_PULLUP) |
| 부저 | D10 |
| LED 파랑 / 빨강 | D11 / D12 |
| 스테핑모터 드라이버 IN1~IN4 | A0~A3 |
| 보드 A | A4 (SDA), A5 (SCL), GND |

배선 그림은 `docs/` 폴더에 있습니다.

## 실행

1. 아두이노 IDE에서 라이브러리 `LiquidCrystal I2C`를 설치합니다.
2. 보드 A에 `jjimkong_board_a.ino`, 보드 B에 `jjimkong_board_b.ino`를 올립니다.
3. 두 보드의 A4, A5, GND를 서로 연결합니다.

## 명령 (블루투스 또는 시리얼 모니터, 9600 baud, 줄바꿈 포함)

| 명령 | 뜻 |
|---|---|
| `H` | 주인이 근처에 있음 (앱이 1초마다 전송) |
| `M글자` | LCD 첫 줄 메시지 변경. 예: `MBACK IN 10 MIN` |
| `T숫자` | 자리 비움 판단 시간(초). 예: `T2` |
| `A` | 지금 바로 경계 시작 (테스트용) |
| `D` | 해제 |
